Python generator, the content it renders and the page it builds.

**Its instructions are in [CLAUDE.md](CLAUDE.md). Read that file first,
then follow its reading order, before reading or changing anything else.**

pointers to every command. This file holds no rule of its own, so nothing
here can drift from it. Claude Code reads CLAUDE.md itself.

  kind of reader, an AI agent included.
